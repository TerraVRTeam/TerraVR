    What you need

    Terraria

    A copy of Terraria on Steam. TerraVR doesn’t include the game.

    tModLoader

    The free, official mod loader. Install it from Steam, next to Terraria.

    A VR headset

    VR support is built into the mod. Ask on the Discord about supported headsets.

    Install in four steps

    1. Install tModLoader from Steam and launch it.
    2. Open Workshop → Download Mods and search for TerraVR.
    3. Download it, then open Workshop → Manage Mods.
    4. Check that TerraVR shows Enabled, then start your world.
